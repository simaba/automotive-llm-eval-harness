# Automotive LLM Eval Harness v0.1.0

**Publication status:** Draft release notes. Complete the public-release checklist before creating a GitHub Release.

## Highlights

- Case-level scoring for fictional automotive and in-cabin assistant evaluation scenarios.
- Six explicit dimensions, validated JSONL input, and duplicate-ID detection.
- Risk-tiered safety/privacy hard gates plus weighted quality thresholds.
- CLI and JSON reporting that distinguishes hard-gate status from overall quality status.
- Public methodology, dataset card, and safe-data policy.

## Intended use

Use this as a compact prototype for organizing synthetic or fully sanitized evaluation evidence. It is useful for teaching, local experimentation, and early rubric design.

## Important limits

- It is not a vehicle-validation suite, safety case, certification artifact, homologation deliverable, or production release authority.
- It does not replace engineering, safety, cybersecurity, privacy, legal, or regulatory review.
- Thresholds are illustrative practitioner defaults and must not be copied into a real program without accountable validation.
